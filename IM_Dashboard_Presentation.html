Project Overview

The IM Dashboard is a centralized internal application that serves as the "Implementation Command Console" for ParentSquare. It establishes a single source of truth for implementation project status, health monitoring, and workflows, integrating with HubSpot, Jira, Zendesk, and ParentSquare usage systems.

The Problem

Implementation Managers currently spend 30-45 minutes per day manually updating HubSpot with implementation status. This leads to fragmented data, reporting delays, and limited visibility into implementation health.

The Solution

A purpose-built dashboard that reduces manual HubSpot updates from 30-45 minutes per day to under 10 minutes (a 75% reduction), provides real-time health scoring, and automatically syncs with HubSpot.

Phase 1 (8-12 weeks) - MVP

  • Core portfolio management
  • HubSpot bidirectional sync
  • Health monitoring with manual override
  • Contact coverage validation

Phase 2 (Months 4-6)

  • Jira CRO integration (read-only)
  • Zendesk support ticket integration
  • ParentSquare usage analytics
  • Advanced health scoring
  • Automated alerting
