## Typography Rules

**Font:** Proxima Nova (available through Adobe Fonts or similar)

If Proxima Nova is not available, use these substitutes:
- **Montserrat** (free Google Font - very similar)
- **Helvetica Neue**
- **Arial** (last resort)

### Display Type (Headlines)
- **Weight:** Bold (Proxima Nova Bold or 700)
- **Alignment:** Left (preferred), centered or right alignment allowed sparingly
- **All Caps:** Only for eyebrow headlines (small text above main headlines)

### Body Copy
- **Weight:** Regular (Proxima Nova Regular or 400)
- **Alignment:** Left (strongly preferred), centered/right OK for small blurbs
- **Emphasis:** Use heavier weights (Semibold 600) for emphasis only, not as main weight

## Logo Usage

### Logo Files Available

- `ParentSquare_logo_light.png` - For light/white backgrounds
- `ParentSquare_logo_dark.png` - For dark backgrounds
- `ParentSquare_Icon.png` - Icon only (for small spaces)

### Logo Placement

**Title Slide:**
- Place logo in top-left or top-right corner
- Recommended size: 250-300px wide
- Maintain aspect ratio (don't stretch!)

**Content Slides:**
- Place smaller logo in corner (100-150px wide)
- Or add to footer area

### Logo Clear Space
- Maintain clear space around logo equal to height of the "P" in ParentSquare
- Don't place text or other elements too close

## How to Apply Branding in PowerPoint

### Step 1: Set Up Master Slide
1. Go to **View → Slide Master**
2. Select the top master slide
3. Insert logo: **Insert → Pictures** → Choose `ParentSquare_logo_light.png`
4. Position logo in top-right or top-left corner

### Step 2: Apply Brand Colors
1. Go to **Design → Colors → Customize Colors**
2. Create a new theme with these settings:
   - **Accent 1:** ParentSquare Green (#85ad33)
   - **Accent 2:** Blue (#7bbaf0)
   - **Accent 3:** Purple (#bc609f)
   - **Accent 4:** Gold (#f2b001)
   - **Accent 5:** Light Green (#e5f1d4)
   - **Accent 6:** Dark Gray (#444444)
   - **Text/Background - Dark:** #333333
   - **Text/Background - Light:** #ffffff
3. Save as "ParentSquare Theme"

### Step 3: Set Default Fonts
1. In Slide Master view, go to **Fonts → Customize Fonts**
2. Set:
   - **Heading Font:** Proxima Nova Bold (or Montserrat Bold)
   - **Body Font:** Proxima Nova Regular (or Montserrat Regular)
3. Save as "ParentSquare Fonts"

### Step 4: Create Slide Layouts

**Title Slide Layout:**
- Background: White or Light Gray (#f7f8f8)
- Title: Green (#85ad33), Large (44-54pt), Bold, Left-aligned
- Subtitle: Dark Gray (#444444), Medium (24-28pt), Regular
- Logo: Top corner, 250-300px wide

**Content Slide Layout:**
- Background: White
- Title: Green (#85ad33), 32-36pt, Bold, Left-aligned
- Body: Dark Gray (#444444), 18-24pt, Regular, Left-aligned
- Use green bullets (set in bullet color options)

**Section Header Layout:**
- Background: Light Green (#e5f1d4)
- Title: Dark Green (#618025), Large (40-48pt), Bold, Left-aligned
- Optional accent: Thin green bar (#85ad33) on left side

## Design Best Practices

### Color Usage

**Green Should Dominate:**
- Use green for all primary headlines
- Use green for important callouts and emphasis
- Green represents school services

**Accent Colors for Meaning:**
- **Blue:** Use for slides about district notifications or classroom communications
- **Gold:** Use for slides about school websites
- **Pink/Purple:** General accent, use sparingly
- **Light Green:** Backgrounds for callouts or section breaks

### Typography Best Practices

✓ **DO:**
- Keep headlines left-aligned
- Use Bold for all headlines
- Use Regular weight for body text
- Use heavier weights sparingly for emphasis
- Maintain consistent font sizes throughout

✗ **DON'T:**
- Don't use all caps except for eyebrow headlines
- Don't center-align long blocks of body text
- Don't make body text bold as the default
- Don't mix too many font weights on one slide

### Layout Tips

1. **White Space:** Don't overcrowd slides - use generous margins and spacing
2. **Hierarchy:** Create clear visual hierarchy with font sizes and colors
3. **Consistency:** Use the same layout structure for similar content types
4. **Bullets:** Keep to 3-5 bullet points per slide maximum
5. **Images:** If using photos, overlay text on solid green or use green frames

## Exporting from PowerPoint

### For Printing
- Export as PDF: **File → Export → Create PDF/XPS**
- Ensure "High Quality" is selected

### For Sharing
- Save as PowerPoint (.pptx) for editing
- Or export as PDF for viewing only

### For Web
- Export as PNG images: **File → Export → Change File Type → PNG**
- Use for embedding in websites or emails
