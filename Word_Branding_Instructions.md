# How to Apply ParentSquare Branding to Word Document

Follow these steps to brand `IM_Dashboard_Executive_Summary_Branded.docx` with ParentSquare identity.

---

## Step 1: Insert Logo

1. **Open** `IM_Dashboard_Executive_Summary_Branded.docx`
2. Click at the very top of the document (before the title)
3. **Insert → Pictures** → Choose `ParentSquare_logo_light.png`
4. **Resize** the logo:
   - Click the logo
   - Drag corner handle to resize (maintain aspect ratio)
   - Make it approximately **2-3 inches wide**
5. **Position**: Center the logo or align left
6. Press **Enter** twice to add space below the logo

---

## Step 2: Apply ParentSquare Colors

### Title Heading (Line 1)
1. Select the text: **"Implementation Manager Dashboard - Executive Summary"**
2. **Home tab → Font Color** → More Colors → Custom
3. Enter **RGB values**:
   - Red: **133**
   - Green: **173**
   - Blue: **51**
   - (This is ParentSquare Green #85ad33)
4. Make it **Bold** and increase size to **24pt**

### Section Headers (## headings)
1. Select each section header (e.g., "Project Overview", "The Problem", "The Solution")
2. **Font Color** → Same green as above OR use Dark Green:
   - Red: **97**
   - Green: **128**
   - Blue: **37**
   - (This is ParentSquare Dark Green #618025)
3. Make sure headers are **Bold**

### Optional: Add Color to Key Stats
For the ROI section and key numbers:
1. Select "467% ROI"
2. Apply ParentSquare Green color
3. Make Bold for emphasis

---

## Step 3: Update Typography

### Change Font to Montserrat (or Arial)
1. **Select All** (Cmd+A or Ctrl+A)
2. **Home tab → Font dropdown**
3. Type "**Montserrat**"
   - If you don't have Montserrat installed, use "**Arial**" as fallback
   - Montserrat is available free from Google Fonts if you want to install it first

### Set Font Weights
- **Headings**: Montserrat Bold (or Arial Bold)
- **Body text**: Montserrat Regular (or Arial Regular)
- **Emphasis**: Montserrat Semibold (or Arial Bold for emphasis)

---

## Step 4: Add Color Accents to Callout Boxes

### Highlight Important Information
For key sections like "Business Impact" or "ROI":

1. Select the paragraph or section
2. **Home tab → Shading** (paint bucket icon)
3. Choose **Light Green**:
   - RGB: Red **229**, Green **241**, Blue **212**
   - (This is ParentSquare Light Green #e5f1d4)
4. Add a **left border**:
   - Right-click selected text → Borders and Shading
   - Click "Borders" tab
   - Select left border only
   - Color: ParentSquare Green (RGB 133, 173, 51)
   - Width: 6pt
   - Click OK

### Alternative: Use Text Box for Callouts
1. **Insert → Text Box → Simple Text Box**
2. Paste important content inside
3. **Format the text box**:
   - Fill: Light Green (#e5f1d4)
   - Border: 4pt, ParentSquare Green (#85ad33)
   - Left-aligned border only for modern look

---

## Step 5: Format Tables (if any)

If your document has tables:

1. Select the table
2. **Table Design tab** → Choose a style OR custom format:
   - **Header row**: Background ParentSquare Green, White text
   - **Alternating rows**: White and Light Green (#e5f1d4)
   - **Border**: 2pt, Green

---

## Step 6: Add Footer with Branding

1. **Insert → Footer → Blank**
2. Add text:
   ```
   © 2025 ParentSquare • Implementation Manager Dashboard
   ```
3. **Format**:
   - Font: Montserrat or Arial
   - Size: 10pt
   - Color: Dark Gray (RGB 68, 68, 68 or #444444)
   - Alignment: Center

4. **Optional**: Add ParentSquare icon in footer
   - Insert → Pictures → Choose `ParentSquare_Icon.png`
   - Resize very small (0.3 inches)
   - Place next to text

---

## Step 7: Save Custom Theme (Optional)

To reuse this styling for future documents:

1. **Design tab → Colors → Customize Colors**
2. Set:
   - **Accent 1**: ParentSquare Green (RGB 133, 173, 51)
   - **Accent 2**: ParentSquare Blue (RGB 123, 186, 240)
   - **Accent 3**: ParentSquare Gold (RGB 242, 176, 1)
   - **Accent 4**: ParentSquare Purple (RGB 188, 96, 159)
   - **Background 2**: Light Green (RGB 229, 241, 212)
3. Save as "**ParentSquare Theme**"

## Pro Tips

1. **Keep it clean**: Don't overuse colors - green for headings and a few callouts is enough
2. **Consistency**: Use the same shade of green throughout (don't mix hex codes)
3. **White space**: ParentSquare design favors clean layouts with breathing room
4. **Typography**: Bold headings, regular body text - don't italicize everything
5. **Print test**: Print a page to make sure colors look good on paper

## Need Help?

If you want to install Montserrat font:
1. Go to fonts.google.com/specimen/Montserrat
2. Download the font family
3. Install on your system (double-click .ttf files)
4. Restart Word
5. Now "Montserrat" will appear in your font list
